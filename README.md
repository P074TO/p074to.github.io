# p074to.github.io

Jr Rob Saluday's personal portfolio, with projects, blog posts, technical
writeups, and retrospectives. Built with [AstroPaper](https://github.com/satnaing/astro-paper).

## Local development

Run `pnpm install` on a fresh checkout, then start the site with `pnpm dev`.
The development server refreshes Astro's content cache on startup.

Posts live in `src/content/posts/`. Use the homelab DNS writeup as a reference
for a post's frontmatter and tag technical writeups with `technical`.
